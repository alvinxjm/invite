# Isabelle's birthday-eve invitation

A rabbit-themed, mobile-friendly invitation from Alvin to Isabelle for a whole-day date on Saturday, 24 October 2026. The venue is a surprise.

Live page: https://alvinxjm.github.io/invite/birthday-2026/

The page is self-contained in `index.html`. Edit that file to change the wording, date, or design; GitHub Pages publishes updates from the repository's `main` branch.

RSVP buttons open a formal acceptance email to `alvinxjm@gmail.com` or a Telegram draft to `@alvinmjx`, addressed to “Dear The Most Handsome And Cute Guy in the World (Alvin),” and signed by Isabelle. The visitor sends the message in their chosen app. No reply is automatically sent or stored by this website. Optional requests are included before the sign-off.

The calendar download reserves 24 October as an all-day event. No specific time or location is published.

Preview locally: run `python3 -m http.server 8765` in this directory and open `http://localhost:8765`.

Layout and RSVP interactions were checked at phone and desktop sizes. Email and Telegram destinations and draft contents were verified without sending test messages.
